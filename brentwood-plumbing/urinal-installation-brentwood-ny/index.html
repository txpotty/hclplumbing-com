    Rough-In Plumbing for Urinals in Brentwood, NY

    Rough-in decides whether the finish goes smoothly. We set the carrier, run a 2 inch waste line to the outlet height on the spec sheet, stub the 3/4 inch supply where the flush valve will land, and tie the vent in before anyone hangs drywall. Inspectors see it open. Then the walls close.

    Urinal Rough-In for New Restrooms in Brentwood

    Tenant improvements need rough-in before the walls close. We space urinals 30 inches apart and 15 inches from side walls, then set carriers and run all the lines. We stay in touch with the GC daily. Rough inspection comes first.

    Residential Urinal Plumbing in Brentwood, NY

    Home urinals use the same rules as commercial ones. The drain is usually 2 inch, the trap is built into the china, the fixture needs a vent within code distance, and the flush valve needs either a 3/4 inch supply or a lower-flow residential valve on 1/2 inch. Permit rules apply too. We check that first.

    Flushometer Urinal Installation in Brentwood

    Manual flushometers are still the most common setup. We install Sloan Royal or Zurn AquaFlush valves on a 3/4 inch supply, adjust the control stop for proper flow, and set the vacuum breaker the right distance above the bowl so it protects the drinking water. Handles can go left or right. ADA units need the handle within reach.

    Waterless Cartridge Urinals in Brentwood

    Each waterless brand uses its own cartridge. A replacement schedule comes with the install. Spare cartridges should stay on site.
