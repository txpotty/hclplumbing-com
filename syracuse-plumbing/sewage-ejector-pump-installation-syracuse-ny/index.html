    Zoeller Ejector Pump Installation in Syracuse, NY

    Zoeller has made ejector pumps for decades, and its cast iron models are the ones we see still running in older basements.     Grinder Pump Installation in Syracuse

    Grinder pumps chop waste into slurry before pumping it, which lets them push through small pipe over long distances. A grinder makes sense when the sewer is distant, uphill or pressurized, such as a pressure sewer where each home pumps into a shared main. Grinders run pricier. A standard ejector often covers a basement bath.

    Cost-Effective Sewage Ejector Pump Upgrades in Syracuse, NY

    Upgrading an old ejector can often keep the existing pit. Cracked basins get replaced.

    Sewage Ejector Pump Basin Installation in Syracuse, NY

    The basin holds everything, and a 30-gallon size is common for a single basement bathroom. Bigger basins let the pump run longer, fewer times a day, which is easier on the motor and switch, so we size up when the pit serves a laundry or several fixtures. Lids must be gas-tight.

    Liberty Pumps Sewage Ejector Pump Installation in Syracuse, NY

    Liberty builds single and dual pump packages that arrive with the basin, pump, lid and fittings matched. Matched packages speed up the install, and Liberty's float design is less likely to snag on the basin wall, a common reason older pumps fail to start. Stuck floats are common.
